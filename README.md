# Calculator

A lightweight web-based calculator built with HTML, CSS, and JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Percentage operation
- Decimal input
- Clear and equals controls
- Memory-style M+ and M- controls
- Simple browser-based interface

## Run Locally

Open `index.html` in a modern web browser.

## Technology

- HTML5
- CSS3
- JavaScript
